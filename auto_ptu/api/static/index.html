Quick start

How to play AutoPTU

1

Build the party

Open Characters to create trainers and Pokémon. Export or save the roster when it is ready.

2

Start the campaign

The GM opens Campaign, creates a table, and shares the invite code. Players join with the Player role.

3

Run the story

Create scenes, set spotlight, speak in character, make checks, tick clocks, update quests, and use Pause / check in whenever needed.

4

Enter battle

Choose a battle setup and press Start Battle. Select the current actor, choose an action, then click a highlighted unit or tile. Press E to end the turn.

5

Plan and interrupt

Press P to queue declarations. Use N to resolve the next declaration. The GM can open a reaction window so players can Stack or Pass.

?

Help at any time

Press ? for this guide. Press Escape to cancel targeting, C to center the selected actor, and T to center the current actor.
